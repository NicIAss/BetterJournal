# BetterJournal v0.1.2

Fixes a startup failure where BetterJournal left the vanilla journal active because another mod's language asset could not be loaded. The reported error was `Requested asset [stablesurface:lang/en.json] could not be found` during `LevelFinalize`.

## Fixes

- Tapestry name lookups now read language files only for domains that provide loaded tapestry designs.
- Optional lore definitions and language files load independently. Missing, unreadable, malformed or empty files are skipped with a warning, so one bad optional file does not stop the reader from being installed.
- An unexpected catalogue setup failure now leaves recovered journal entries readable, with optional totals and tapestry metadata unavailable for that session.
- Selected-language tapestry names, English fallback, mod-qualified names and specific wildcard matches remain supported.

Stable Surface adds no lore or tapestry content and is not a BetterJournal dependency. Its language file is no longer needed by BetterJournal. No changes to other mods are required for this fix.

## Update

For **Vintage Story 1.22.7**, client-side only.

1. Close the game.
2. Replace the old BetterJournal ZIP in the active profile's `Mods` folder with **BetterJournalv0.1.2.zip**. Keep only one copy enabled and keep the ZIP zipped.
3. Restart the game, enter your world/server, and press **J**, or your remapped journal key.

Existing worlds, recovered lore, bookmarks and locally saved tapestry progress are retained. The server does not need BetterJournal. The local progress format is unchanged.

Lore translations depend on the game/content mod. Tapestry names prefer the selected language and use English where that translation is missing and English is available. BetterJournal's own interface labels currently ship in English. Restart the game after changing its language.

## Validation

- Release build against installed Vintage Story 1.22.7 assemblies: **144 automated checks passed**, zero compiler warnings/errors, including six new optional asset regressions.
- In-game smoke test with Stable Surface and an isolated 89-mod profile: bookshelf and the 31-design vanilla tapestry gallery opened successfully; restarting the client enabled the reader again without the reported exception.
- The test profile was not an exact copy of the reporter's setup: one custom mod was unavailable and three mod versions differed. Full retesting on the original multiplayer server remains outside this smoke test.

The release includes **BetterJournalv0.1.2.zip** and **BetterJournalv0.1.2.zip.sha256**. GitHub also provides source archives for tag `v0.1.2`.
