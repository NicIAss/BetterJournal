# ModDB page

- `summary.txt`: short summary for the ModDB summary field.
- `description.html`: HTML fragment to paste into the description's source editor.
- `preview.html`: local preview with relative screenshots and collapsible sections. Its wrapper/script are preview helpers, not part of the paste fragment.

The page reuses the supplied BetterTraders page's cream background, buttons, spoiler sections and design credit. It uses plain feature sentences and the BetterJournal repository/issue URLs. The Discord invite is retained from the supplied template. There is no BetterTraders team banner, world-generation copy or hidden trader-keyword block.

Production screenshot URLs point to `raw.githubusercontent.com/NicIAss/BetterJournal/main/docs/images/`. The BetterJournal repository is currently private, so those images will only work publicly after the repository is made public as part of the approved release. The local preview uses the included screenshots and works before that. No page or public image upload has been published.

When editing the description, keep the preview's body synchronized with the fragment; only screenshot URLs differ. Progress behavior is documented in [PROGRESS.md](../PROGRESS.md).
